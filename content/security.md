PlainSight Lab — operating under **Plainsight Systems LLC** — treats security as a first-order concern. The full security posture and responsible-disclosure policy are published as governance artifacts in the Docs section.

---

## Reporting a vulnerability

If you have identified a security vulnerability in plainsightlab.com, in associated infrastructure, or in published artifacts, email:

**security@plainsightlab.com**

For machine-readable contact metadata at the holding-company level, see the parent entity's [security.txt](https://plainsight-systems.com/.well-known/security.txt) (RFC 9116).
